# 🚀 Modern Animated Website

A modern, interactive website built to explore the latest web design trends, smooth scrolling, and engaging animations. This project combines creative UI design with animation libraries to deliver a dynamic browsing experience.

🌐 **Live Demo:** https://lazarevclone-ten.vercel.app/

## ✨ Features

- Modern and visually engaging UI
- Smooth animations and transitions
- Smooth scrolling experience
- Interactive navigation and UI elements
- Responsive layout (where implemented)
- Deployed on Vercel

## 🛠️ Tech Stack


| HTML5 --> Website structure 
| CSS3 --> Styling and layouts 
| JavaScript --> Interactivity and functionality 
| GSAP --> Animations and transitions 
| Locomotive Scroll --> Smooth scrolling effects
| Vercel --> Deployment and hosting
